# 💰 CashCompass

### Directing your money, daily.

CashCompass is a personal finance management application designed to help users manage their income, expenses, budgets and financial activity from one place.

The application provides authentication, email OTP verification, password reset, financial dashboards, transaction management, budgeting, reports, AI-powered financial insights and downloadable PDF reports.

---

# 🚀 Features

## 🔐 Authentication

- User Registration
- Email OTP Verification
- Resend OTP
- Login
- Logout confirmation
- Forgot Password
- Password Reset using OTP
- Password visibility toggle
- Form validation
- Authentication error handling

---

## 📊 Dashboard

The dashboard provides an overview of the user's financial position.

Includes:

- Total Income
- Total Expenses
- Total Savings
- Budget Status
- Budget Utilization
- Savings Rate
- Expense Rate
- Financial Direction
- Recent Transactions
- Six-month financial activity chart

---

## 💵 Income Management

Users can:

- Add income
- View income
- Track income by date
- View income history
- Monitor financial activity

---

## 💸 Expense Management

Users can:

- Add expenses
- View expenses
- Track expenses by date
- View expense history
- Monitor spending

---

## 💳 Transaction Management

Users can:

- View transactions
- View recent transactions
- Sort transactions
- Navigate through transaction history

---

## 🎯 Budget Management

Users can:

- Create budgets
- Monitor spending
- View budget utilization
- Track remaining budget
- Monitor budget percentage

---

## 📈 Financial Reports

Reports include:

- Income vs Expense comparison
- Twelve-month financial chart
- Monthly financial data
- Monthly balance
- AI financial insights
- Financial recommendations
- AI-generated financial summary

---

## 🤖 AI Financial Insights

CashCompass can generate AI-powered financial observations based on the selected month.

AI insights may include:

- Financial summary
- Spending observations
- Income observations
- Recommendations
- Financial warnings

---

## 📄 PDF Financial Reports

Users can generate and download monthly financial reports as PDF files.

The report can contain:

- Income
- Expenses
- Savings
- Budget position
- AI financial observations
- Monthly financial summary
